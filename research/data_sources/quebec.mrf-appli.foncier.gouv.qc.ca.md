# Quebec Provincial Parcel/Cadastral Data

## What

Ministère des Ressources naturelles et des Forêts (MRF) keeps a ArcGIS Mapserver that provides access to some geographic data related to parcel lots and other land oriented information. 

The ArcGIS server is version 10.91 (2022) and can be found [here](https://appli.foncier.gouv.qc.ca/arcgiswa/rest/services).

The MRF has an interactive map for parcel lots available [here](https://appli.foncier.gouv.qc.ca/Infolot/Info/DescriptionServiceGratuit). For free, one can use the map to find lots and lot numbers. But virtually all other data costs money.

All of this is image (raster) data. For vector data, there is a separate service offered for bulk data downloads/extraction. [Given their rates](https://appli.foncier.gouv.qc.ca/Infolot/Info/TarificationExtraction), the cost for the island of Montreal would likely be prohibitive.
