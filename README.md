# BriqueParBriqueData

## Overview
[Brique par brique](https://www.briqueparbrique.com/) (BxB) is a social housing organization that competes with traditional developers to provide community housing and infrastructure for social change. Finding ideal opportunities for acquiring properties has been a challenge due to the quantity of data and the current manual process of data gathering and case-by-case evaluation. The goal of this project is to simplify, streamline, and automate this process such that the burden on the BxB team is reduced and they are able to find more ideal opportunities.
